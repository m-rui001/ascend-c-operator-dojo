# 特性

- 不支持虚函数
- 不支持虚继承
- 不支持运行时递归
- 不支持动态malloc、new/free
- 不支持STL
- 不支持运行时typeid
- 不支持文件系统IO
- 不支持标准库下的tuple及算法类运算（相关库函数调用需要标记aicore）
