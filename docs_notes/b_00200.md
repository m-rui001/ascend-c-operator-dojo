# 接口变更说明

为了优化API命名，使其更加清晰和易于理解，当前版本相比于CANN8.5.0及前序版本，部分API命名有变更，具体变更情况请参考以下表格：

| 原接口名 | 新接口名 | 备注 |
| --- | --- | --- |
| ScalarGetCountOfValue | GetBitCount | 无 |
| ScalarCountLeadingZero | CountLeadingZero | 无 |
| ScalarGetSFFValue | GetSFFValue | 无 |
| ScalarCast | Cast（float转half、int32\_t） | 无 |
| ToBfloat16 | Cast（float转bfloat16\_t） | 无 |
| ToFloat | Cast（多类型转float） | 其中一个重载版本的返回值类型由float改为模板U, U = float |
| FusedMulAddRelu | MulAddRelu | 无 |
| CastDeq | CastDequant | 无 |
| CompareScalar | Compares | 无 |
| GetAccVal | GetReduceRepeatSumSpr | 无 |
| GetReduceMaxMinCount | GetReduceRepeatMaxMinSpr | 无 |
| SetAtomicNone | DisableDmaAtomic | 无 |
| InitConstValue | Fill | 无 |
| SetMMLayoutTransform | SetMMRowMajor/SetMMColumnMajor | SetMMLayoutTransform(true)对应SetMMRowMajor()。 SetMMLayoutTransform(false)对应SetMMColumnMajor()。 |
| SetHF32Mode | SetHF32Mode | 接口名不变，参数类型由bool修改为枚举HF32Mode。 |
| SetHF32TransMode | SetHF32TransMode | 接口名不变，参数类型由bool修改为枚举HF32TransMode。 |
| CalcTschBlockDim | CalcTschNumBlocks | 无 |
